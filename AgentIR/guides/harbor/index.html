    Harbor and Terminal-Bench¶

    AgentIR ships a Harbor 0.16.1 agent, agentir.integrations.harbor.agent:AgentIRHarborAgent. Harbor owns the task container and trial lifecycle; AgentIR owns the model program, which is infer(instruction, tools={"shell": ...}) with the container's shell as the one tool.

    Install¶

    Harbor needs Python 3.12 or newer. From the AgentIR checkout:

    uv venv --python 3.12 .venv-harbor
source .venv-harbor/bin/activate
uv pip install -e '.[harbor]'

    Start a certified vLLM server for the model you want to evaluate.

    Run a trial¶

    harbor run \
  --dataset terminal-bench@2.0 \
  --agent agentir.integrations.harbor.agent:AgentIRHarborAgent \
  --model openai/Qwen/Qwen3-Coder-30B-A3B-Instruct \
  --agent-kwarg model_endpoint=http://127.0.0.1:8000/v1 \
  --agent-kwarg runner_backend=remote_vllm_tier1 \
  --agent-kwarg spec_enabled=false \
  --agent-kwarg max_turns=32 \
  --agent-kwarg shell_timeout_sec=120 \
  --n-concurrent 1

    spec_enabled=true is the speculation-on arm; it sets SpecConfig.enabled for real, not just a label. runner_backend=in_process_vllm loads the model in the Harbor process instead (install the vllm extra there); there is no fallback between the two backends.

    How the shell tool crosses the boundary¶

    Harbor's environment is asynchronous and owns the event loop. The synchronous AgentIR program runs in a worker thread; every shell call is posted back to Harbor's loop with run_coroutine_threadsafe, and trial cancellation propagates to in-flight commands.

    The shell ToolDef has effect="unknown": no speculative branch ever runs a command. Its observation policy renders one canonical JSON image with stdout, stderr, return code, timeout flag, error, and truncation metadata (each stream capped at 65,536 characters, head and tail preserved). Its predictor guesses the common silent-success image, so the model's next turn can be decoded while a committed command is still running; exact comparison decides whether that turn survives. A malformed call is reported back to the model as an observation rather than aborting the trial.

    What gets recorded¶

    The adapter writes an ATIF v1.7 trajectory after every observation, so a timeout still leaves an auditable record. Each shell step keeps the raw provider result, timing, and effective timeout. The final step carries token counts from the ledger, the effective backend and endpoint, the certificate digest, and the full runtime configuration. Warmed runtimes are cached per exact configuration and arm, reference-counted, and fork-aware; close_cached_runtimes() releases them.

    Configuration¶

    All runner settings are AGENTIR_HARBOR_* environment variables, read once per process:

    Variable Default Meaning
    BACKEND remote_vllm_tier1 default backend; runner_backend overrides per trial
    TIER1_ENDPOINT trial endpoint explicit server base URL
    TIER1_API_KEY unset bearer token
    TIER1_EXPECTED_VERSION 0.24.0 server version pin; empty disables the pin, not the certificate
    TIER1_EXPECTED_CERTIFICATE_SHA256 unset exact deployment pin
    MAX_INFLIGHT 32 engine request cap
    MAX_TOKENS 1024 per-turn budget
    MAX_CALLS 8 pre-reserved call slots per turn
    TEMPERATURE 0 plus optional TOP_P, TOP_K, MIN_P, PRESENCE_PENALTY, REPETITION_PENALTY
    INFERENCE_TIMEOUT_SEC 1800 tool-loop, decision, and drain timeout
    BRIDGE_GRACE_SEC 15 extra time for the shell bridge to cancel
    OUTPUT_CHAR_LIMIT 65536 per-stream image cap
    SPEC_WINDOW, MAX_SPEC_INFLIGHT 2, 8 speculation window and budget
    RUN_SEED 20260708 runtime seed
    ENGINE_ARGS, DEVICES {}, unset in-process backend only
    THINKING_TOKEN_BUDGET, CHAT_TEMPLATE_KWARGS unset, {} server render controls
    SYSTEM_PROMPT built in the terminal-agent system prompt

    runner.py validates every value; the effective configuration is archived in the trajectory.

    A custom runner¶

    Set runner_import_path=module:callable to replace the model side while keeping Harbor's environment and trajectory handling. The contract is an async callable (RunnerRequest, execute_shell) -> RunnerResult, where execute_shell(ShellRequest) -> ShellObservation and optionally exposes .reject(arguments, error) for calls the runner refuses to execute. The types live in agentir.integrations.harbor.protocol and have no Harbor dependency, so a runner can be tested without Harbor installed.

    Formal Terminal-Bench experiments use locked launchers and analyzers; see the experiment archive.
