    Remote execution¶

    make_remote_runtime runs the AgentIR tracer and scheduler on the client while a certified vLLM Tier-1 server owns tokenization, chat rendering, model execution, and tool parsing. The client needs neither local vLLM nor a local tokenizer.

    This is a specific token-in/token-out protocol. A server exposing only an OpenAI-compatible chat endpoint does not satisfy it.

    Prepare the server¶

    Install the same AgentIR checkout into the server's vLLM 0.24.0 environment, so its middleware is importable. The following is a server launch template for the Qwen3-Coder tool family; choose context, memory, and model revision settings appropriate to your hardware:

    python -m vllm.entrypoints.openai.api_server \
  --model Qwen/Qwen3-Coder-30B-A3B-Instruct \
  --host 127.0.0.1 \
  --port 8000 \
  --enable-auto-tool-choice \
  --tool-call-parser qwen3_xml \
  --middleware agentir.execution.vllm_certificate.middleware \
  --scheduling-policy priority \
  --enable-prefix-caching \
  --generation-config vllm

    The parser must match the selected model family. The checked-in experiment launcher is hephaestus_terminal_bench_paired.sbatch; its cluster paths, resource allocations, and experimental locks are specific to that environment.

    Probe the certificate route after startup:

    curl --fail http://127.0.0.1:8000/v1/agentir/tier1/certificate

    An unavailable certificate or incompatible server is a setup failure. Do not substitute stock render routes to bypass the handshake.

    Connect the client¶

    from agentir import force, infer, lit, make_remote_runtime, out_text


def program():
    return force(out_text(infer(lit("The capital of France is"), max_tokens=32)))


if __name__ == "__main__":
    with make_remote_runtime(
        model="Qwen/Qwen3-Coder-30B-A3B-Instruct",
        base_url="http://127.0.0.1:8000",
    ) as runtime:
        print(runtime.run(program))

    The remote runtime always uses the token wire and exposes main with a judge alias. A trailing /v1 on the endpoint is normalized to the server base. Pass an API key or headers through the constructor when the server requires them.

    Follow one request¶

    Stage Route Purpose
    Handshake /version and /v1/agentir/tier1/certificate Check the pinned version and bind the server contract
    Render /v1/agentir/tier1/render Convert the conversation into exact prompt tokens and request settings
    Generate /inference/v1/generate Execute token-in/token-out inference
    Derender /v1/agentir/tier1/derender Interpret the final tokens using the certified parser and template
    Token conversion /tokenize, /detokenize Provide the remote token-wire operations

    The certificate binds the model and tokenizer revisions, template and parser implementation, and required features. Requests and responses carry certificate-digest and instance-ID headers. An instance change invalidates cached assumptions even if the visible model name stays the same.

    certificate_mode="required" is the supported default. expected_certificate_sha256 can pin an exact deployment contract for a controlled experiment. Version checks alone cannot establish parser or rendering equivalence.

    Know the streaming boundary¶

    The client reads generation SSE incrementally, but buffers the semantic tool projection until generation and derendering finish. Remote tool calls are published at the terminal boundary. It does not provide the local adapter's early per-call dispatch during model decoding.

    After a call is available, a predicted next turn can still overlap the real tool execution. Keep these two overlap opportunities separate when comparing local and remote runs.

    Cancellation and caching¶

    Cancellation closes the exact active HTTP connection. Successful ordinary JSON requests can reuse pooled HTTP/1.1 connections; generation SSE connections are not reused. A bounded render cache stores successful results for exact canonical requests within the certified instance, with singleflight coordination for concurrent identical renders.

    The default render cache holds 128 entries. Restart or handshake changes fence old cache entries and attempts. The client's restart path can re-handshake; it does not launch or repair the external service.

    Capabilities that cannot be safely checked remotely are rejected. For example, the current adapter cannot perform the required structural_tag preflight and fails closed for that feature. Higher provider protocol tiers discussed in research material are not additional implemented backends.

    Source: remote.py, vllm_certificate.py, and remote protocol tests.
