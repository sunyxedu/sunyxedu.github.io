    Static shape compilation¶

    agentir.compile.shape_trace runs a program once over symbolic values and returns its structure as a graph: every engine-node shell, op, decision, loop body with its back-edge, and bounded tool slot, before any model is loaded. Use it to see what the tracer will build, to serialize a program's shape, or to produce a per-decision funding plan for the scheduler.

    Compile a program¶

    This runs with the base install and no GPU:

    from agentir import cat, choose, collect, expand, force, infer, lit, op, out_text
from agentir.compile import shape_trace


def rank_by_length(answers):
    return sorted(range(len(answers)), key=lambda i: len(answers[i]))


def program(question):
    candidates = expand(lit(question), 3, max_tokens=64)
    answers = collect([out_text(c) for c in candidates])
    ranking = op(rank_by_length, answers, pure=True)
    best = choose(candidates, by=ranking, k=1)[0]
    final = infer(cat(best, lit("\nSummarize:")), max_tokens=32)
    return force(out_text(final))


graph = shape_trace(program, "Explain prefix caching.")
print(graph.summary())
with open("program-shape.json", "w", encoding="utf-8") as output:
    output.write(graph.to_json())

    The summary lists three expand shells, a collect op, a ranking op, one choose, and one guarded infer continuation. rank_by_length was never called on real text: op returns a symbol, and only a Python branch on a symbol is refused.

    How it works¶

    The shape tracer is a third context that duck-types the serial hooks: serial = True routes every primitive to it, exactly like the reference interpreter, so no new dispatch path exists in the DSL. Each primitive emits one trace event per node shell. Identity parity is structural, not re-derived: draws come from the same DrawLedger, parameters merge through the same validation, and spine templates canonicalize with the same literal merge, so a shell's precomputed identity chunks finalize to exactly the NodeId the live tracer mints once the dynamic hole digests are known.

    ShapeChoice is the compiled form of the hoist: one parametric shell stands for every member's world instance, with a sel segment in its spine instead of n copies.

    Loops become loops¶

    The fold pass detects consecutive isomorphic blocks in the event stream (same signatures, references that shift by exactly the period, or point to the same pre-loop node) and collapses them into one body plus back-edges annotated with a trip count. A block that continues the problem literal in round 0 and a selection afterwards is absorbed as the first iteration with its literal as the init binding, so for t in range(rounds) folds to trip_count == rounds. A Python map over an array, whose references slide through pre-region values, is correctly not a loop. loop declares its structure, so the tracer emits it pre-folded with a bound trip; so does the tool loop, whose turns fold to one assistant shell plus max_calls slot shells.

    Read the graph¶

    Element Meaning
    node shell the static part of an engine request, op, decision, or tool slot, with an identity prefix when one exists
    cat_data edge spine concatenation
    transform_data edge an opaque op
    control edge a selection determines whether the target survives
    loop body shell ids, trip count and kind, carried ports with init bindings
    guard pool size, k, continuations, and the maximum useful speculation depth below it

    Shells whose identity binds at run time (tool slots, chat-rendered turns, dynamic-literal holes) carry an identity_note instead of a prefix. StaticGraph.from_json round-trips the JSON.

    Produce a funding plan¶

    from agentir import SpecConfig

spec = SpecConfig(static_plan=graph.plan())

    plan() lowers the guard structure to a StaticPlan: per decision site, a speculation-depth bound (from the longest chain of selections below it, or the global window when a loop back-edge makes it unbounded) and a sibling budget of k, since at most k of P members commit and funding more distinct members' subtrees is provably waste. The scheduler matches decisions by call site. A plan is capacity policy only: guards, identity, committed admission, and results are untouched. See static plans.

    Graph breaks¶

    Any bool, len, int, str, iteration, or membership test on a symbol raises GraphBreak with the file and line of the branch. So does chat_prefix (it needs the engine's template) and the observation-decision primitives expect and classify. A graph break is a compiler boundary, not a runtime bug: the program still runs normally under the live tracer, just without a plan.

    Source: compile/tracer.py, fold.py, graph.py, symbols.py; tests test_compile_shape.py, test_compile_plan.py.
