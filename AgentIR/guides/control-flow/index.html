    Branching and loops¶

    Use choose, gate, and loop whenever a decision determines which already-describable work survives. Use ordinary Python when the next request truly cannot be built without a concrete value; that is a barrier, and it is fine, just visible.

    Select and continue¶

    The core pattern keeps the ranking asynchronous:

    candidates = expand(prompt, 3, max_tokens=128)
scores = collect([op(score, out_text(c), pure=True) for c in candidates])
ranking = op(rank_desc, scores, pure=True)        # Val[list[int]], best first
best = choose(candidates, by=ranking, k=1)[0]
answer = infer(cat(best, lit("\nConclude in one line.")), max_tokens=64)

    ranking must resolve to distinct integer positions into the pool, at least k of them, best first. A bare int is the k=1 shorthand. Scores, booleans, or repeated positions fail the decision and the failure surfaces at consumers.

    Ask for k > 1 to keep several ranks. Each element is a rank-specific Choice:

    top2 = choose(candidates, by=ranking, k=2)
merged = infer(cat(lit("A: "), top2[0], lit("\nB: ")))   # one Choice per cat

    cat distributes over one unresolved Choice. It refuses two independent ones; force one first, or restructure around a single decision.

    A hint= list of per-member Vals (the scores, say) tells the scheduler which member's continuations to fund first as evidence arrives. It cannot change the result. See optimizations.

    Keep or drop¶

    keep = op(needs_detail, out_text(draft), pure=True)      # Val[bool]
more = infer(cat(gate(draft, keep), lit("\nAdd the missing detail.")))

    gate(x, cond) keeps x when cond is true and has no false branch: forcing more when keep is false raises Squashed. Use it for work whose absence is fine, or inside a larger choose where the other branch provides the fallback. The cascade algorithm gates an expensive escalation on a rejection verdict so it decodes early only when speculation is on.

    Iterate until a condition says stop¶

    def revise(state):
    review = infer(cat(state, lit("\nReview this answer.")), max_tokens=96)
    again = op(needs_revision, out_text(review), pure=True)   # Val[bool]
    revised = infer(cat(review, lit("\nWrite the revised answer.")), max_tokens=192)
    return revised, again

result = loop(draft, revise, max_iters=3)

    body(state) returns (next_state, continue). Return the condition as a Val; do not force it to decide in Python. The tracer traces round t+1 under the assumption that round t continues, up to lookahead unresolved rounds ahead (default: the speculation window). If the condition turns out false, the extra rounds are squashed as a whole.

    The returned state is the one that entered the stopping round

    When round t's condition is false, loop returns states[t], the state that entered round t, not the next_state that round proposed. In the example, a review that accepts the current answer returns that answer, not a revision of it. If every condition is true through max_iters, the last next state is returned.

    The reflexion algorithm is this loop with a judge-role critic; read reflexion.py for the full version.

    Hand-written round loops¶

    A for loop that feeds each round's selection into the next round's expand is fine, but the hoist multiplies: with every earlier selection unresolved, round t registers pool^t guarded continuations. Call pace_unrolling (from agentir.api) once per round with the selections so far; it blocks while more than lookahead of them are unresolved. If you skip it, the tracer stops you at 4096 world instances per call with an error naming the fix. Beam search in the algorithm library shows the pattern, including where in the round body to place the pace.

    What becomes a barrier¶

    You write Effect Alternative
    force(ranking) then index the pool in Python selection is a full stop pass the Val to choose
    lit(force(out_text(x)) + suffix) the tracer waits for the text and loses the spine link cat(x, lit(suffix))
    infer(some_val) where the Val holds a Seq waits for the value first expose the pick as a choose
    if handle: TypeError: a handle has no truth value gate, choose, or a deliberate force
    side effects inside op(..., pure=True) the purity promise is broken; the effect may run in a losing world default op, or a tool

    Barriers are correct. They cost the overlap you would otherwise get, and a timeline makes them easy to spot.
