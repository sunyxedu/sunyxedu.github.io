    Programs and handles¶

    An AgentIR program is a Python function that calls eight primitives. The primitives never return strings. They return handles: symbolic values that describe work and remember what it depends on. This page explains the three handles and the primitives that create and consume them. The rest of the pipeline exists to execute what these handles describe.

    Why handles instead of strings¶

    If infer returned the generated text, the program would have to wait for it before doing anything else, and every decision would become a full stop. Returning a handle lets the tracer keep running ahead: it can build a prompt that refers to an output that does not exist yet, hash that prompt, and register the request. The scheduler fills in the bytes later.

    Handles also carry provenance. When you concatenate a candidate into a judge prompt, the judge node records a data edge to the candidate node. That edge is what tells the scheduler when the judge can start, and what lets the engine's prefix cache reuse the candidate's KV blocks.

    The three handles¶

    Handle Stands for Readable? Created by
    Seq An immutable token sequence: a canonical spine of literal segments and symbolic output segments. Only through an exit: text, out_text, force. lit, cat, fmt, infer, expand, obs
    Val[T] A control-plane future. Carries the node ids it awaited and the entry guard of the world it was created in. force(val), or as an input to another op. op, collect, out_text, text, logprobs_of, observe, ack
    Choice Rank r of decision d over a pool: "whichever member d ranks r-th". Never blocks. Only after binding: force, or continue it with infer/cat. choose, gate, expect, classify

    All three raise TypeError on bool(). A handle has no truth value yet; the silent always-true reading of an object would be a bug waiting to happen, so it is refused at the coercion site.

    Seq: state semantics¶

    infer(x) returns x's spine plus a new output segment. That is, a Seq is a state, not a delta:

    draft = infer(prompt)                 # spine: [Lit(prompt), Out(draft_node)]
review = infer(cat(draft, lit(ask)))  # spine: [Lit(prompt), Out(draft_node), Lit(ask), Out(review_node)]
text(review)      # Val[str]: prompt + draft + ask + review
out_text(review)  # Val[str]: just the review

    Two Seqs with the same spine are the same handle (key is a content hash of the spine). Adjacent literals are merged and empty ones dropped, so how you happened to build a prompt does not change its identity.

    Val: content untracked, world tracked¶

    A Val wraps a concurrent.futures.Future, but it is more than a future. It records depends_nodes, the engine nodes whose output it transitively awaited, and entry_guard, the guard under which it was minted. Exits use the first to know what to wait for; force uses the second to refuse to publish a value from a world that lost.

    An op runs its function on a worker pool as soon as its inputs resolve. With pure=True that may be on speculative data. With the default pure=False the op is an execution-delay barrier: it waits until its entry guard is true and every dependency it will read has committed, and it runs at most once. Declare pure=True only for deterministic functions with no external effects; it is a promise you make, not something Python checks.

    Choice: a placeholder with a decision behind it¶

    best = choose(candidates, by=ranking, k=1)[0]   # Choice(d, rank 0)
top2 = choose(candidates, by=ranking, k=2)      # [Choice(d, 0), Choice(d, 1)]

    A Choice holds a Decision and a mapping from member key to member handle. derive(fn) maps every member, which is how cat(best, tail) produces a new Choice over cat(A, tail), cat(B, tail), and so on. bound() returns the concrete member once the decision resolved, or None if this rank does not exist in that world (a false gate, or a failed decision's empty resolution).

    The eight primitives¶

    Primitive Role What it registers
    lit(s) / cat(*xs) Build prompts Nothing: pure spine construction
    infer(x, **params) Continue once One engine node per possible world of x
    expand(x, k, **params) k continuations k nodes with identical prompts and distinct lanes of one draw
    text(x) / out_text(x) Observe A Val[str] exit; provenance stops here
    op(f, *args, pure=...) Compute on the control plane A pooled task; pure chooses replay-on-speculation or barrier
    choose(pool, by, k) Select by index A Decision and k Choice placeholders
    gate(x, cond) Keep or squash A two-slot decision with only a keep member
    loop(init, body, max_iters) Repeat with an entry predicate One gate decision per round, traced ahead of resolution

    Helpers: collect gathers Vals in list order without occupying a worker per element; force is the blocking, publication-checked exit; fmt is cat with named holes; logprobs_of and top_logprobs_of read observation channels requested at generation time.

    Two effect classes¶

    Everything on the control plane is one of two things:

    • Pure: replayable. May run on speculative inputs; its result and its exceptions are published only when its world commits, and the exits enforce that.
    • Unknown: the default for op, and for tools. Fenced until its entry guard is true and the dependencies it actually reads have committed. Runs at most once. Never retried.

    An op whose result is a handle is not a routing mechanism. Continuing from a Val that holds a Seq makes the tracer wait for the value first. It is correct, merely slow. A program that wants speculation at a selection exposes that selection as a choose.

    What the rule "selection routes by index" buys¶

    Because choose returns positions into a pool that already exists, the set of possible continuations is finite and known at trace time. That is the precondition for the hoist in the tracer. It also means a ranking function, however elaborate, cannot inject new tokens into the dataflow: Seq has no public constructor from a string other than lit, and a Seq handed to a tool argument is rejected. The only way content leaves a Seq is an explicit exit, which is a provenance barrier by definition.

    In the code¶

    • core/ir.py: Lit, Out, Obs segments and canon.
