    Glossary¶

    Term Meaning
    Agent branch speculation Executing possible agent continuations before a selection decides which survive
    Attempt One physical execution of a logical engine request; retries create new attempts
    Bound commit Algorithmic truncation after strict rival-score evidence proves a candidate cannot enter the selected top-k
    Choice A symbolic handle for one rank of an unresolved selection
    Commitment Permission for completed work to belong to the surviving computation
    Control plane Python operations and decisions that coordinate model and tool work
    Data dependency Input content that must exist before a request can be constructed or issued
    Decision A ranked selection or boolean gate with an entry guard
    DrawId A sampling occurrence identified by call site, scoped occurrence, and expansion lane
    Engine node / E-node A logical model request with a frozen prompt descriptor and observation contract
    Epoch An engine generation used to fence stale attempts and events across recovery
    Guard A conjunction of conditions under which a node survives
    Hoisting Rewriting a continuation of a choice into guarded continuations of its possible members
    Hole A declared observation slot filled by the real projected tool result
    IR Intermediate representation: the graph and symbolic values between the Python program and execution
    Invocation One execution of a program in a fresh tracing context
    Ledger Per-node records of registration, issue, completion, guard timing, and disposition
    NodeId Content-addressed identity of a logical request, independent of its physical attempt
    Observation image The string or canonical JSON representation exposed by a tool's declared projection
    Observation policy A tool contract that projects results, declares candidates, and selects among them
    Prefix caching Engine reuse of computation for matching prompt-token prefixes
    Projection A pure, named view of a tool result, or a declared interpretation of streamed model output
    Seq An opaque symbolic prompt state, including prior prompt segments and generated output
    Speculable effect A declaration that extra tool executions and retries are safe under the intended observation contract
    Spine Canonical sequence of Lit, Out, and Obs segments that describes a prompt
    Squash Reject a world and cancel its active work without publishing its result
    Static shape A symbolic graph of possible program structure, with loop bodies and dynamic holes
    Tier-1 The implemented certified remote render / token-in-token-out / derender protocol
    Token drafting Engine-level candidate-token generation followed by token verification
    Tool node / T-node A logical tool body identified by name, canonical arguments, draw, and effect contract
    Unknown effect A conservative contract that fences body execution until its world is committed
    Val An asynchronous Python value carrying dependency and guard information
    Weak control dependency A keep-or-cancel condition that does not supply request input bytes
    Window The eligible unresolved guard depth for speculative issue
    Wire The representation of prompt atoms: strings or exact token-ID tuples
    World One combination of selection outcomes under which a handle instance exists
