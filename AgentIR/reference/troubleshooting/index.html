    Troubleshooting¶

    Find the boundary that failed: import, engine start, tracing, a decision, tool parsing, or the differential. Then reduce to the smallest program that reproduces it.

    Installation and engines¶

    Symptom Cause Fix
    agentir does not import wrong environment python -m pip install -e . in the environment that runs the program
    "vLLM is not installed" base package only install the vllm extra, or use make_remote_runtime
    the engine starts again and again runtime created at import time move it under if __name__ == "__main__":
    out of memory context, concurrency, or two engines on one card lower max_model_len, gpu_memory_utilization, max_inflight; pin judge_devices
    "engine version X != pinned 0.24.0" version drift re-certify on the new build or set expected_version=None knowingly
    "AgentIR requires vLLM scheduling_policy='priority'" engine_args overrode it remove the override
    token-wire runtime rejects two engines tokenizer programs differ use the same model id for both roles, or the text wire

    Tracing¶

    TypeError: Seq is a traced handle with no truth value. You branched on a handle. Use gate, choose, or loop, or force deliberately.

    NotImplementedError: cat over two independent choices. Force one selection first or fold both into one decision.

    RuntimeError: hoist over draw ... more than 4096 world instances. A hand-written round loop is unpaced. Call agentir.api.pace_unrolling(selections) once per round, or use loop.

    The output contains the prompt. text reads the whole state; out_text reads the generated tail.

    loop returned an older state than expected. A false condition returns the state that entered that round. Put the accept/reject logic around that contract.

    GraphBreak under shape_trace. Only the compiler is affected; the program still runs under the live tracer. The message names the branch.

    Decisions and cancellation¶

    Squashed from force. You published a rejected world: a false gate with no alternative, or a losing handle that escaped its branch.

    RankingError. Return distinct in-range integer positions, at least k of them, best first. Not scores, not booleans.

    TimeoutError: decision ... unresolved after 600s. A ranking or condition never resolved. Check that its op can complete and that nothing waits on a future that waits on it. Raise or disable SpecConfig.decision_timeout for genuinely slow judges.

    A cancelled tool still ran. A body that started cannot be stopped; only unstarted speculative bodies are cancelled. Declare effect="unknown" for anything that must not run in a losing world.

    Tools and remote¶

    Symptom Check
    "requires a token wire" tool loops need wire="tokens"
    "no audited vLLM tool family for model" the model is outside the family table; pass an explicit ToolFamilyProfile to the projection, or choose a supported model
    the tool gets keyword arguments bodies receive one dict
    unexpected small model requests ToolDef(fn) enables the default draft predictor; pass obs=Exact() or guess=None
    ProjectionError from select selectors return a declared slot index or None; custom errors are errors, not misses
    ProjectionDivergence a retry or the terminal parser disagreed with published calls; do not swap parsers to silence it, find the mismatched template, parser, or model
    state leaks between calls override Policy.new_session to allocate nested mutable state
    certificate route returns 503 the server's parser pair is outside the audited set, or a plugin is loaded
    HTTP 412 / 428 from the server the server instance or certificate changed; the client re-handshakes once, then poisons
    remote calls only arrive at turn end expected: remote mode is terminal-only

    Correct but slower¶

    Look at a timeline before touching window. Common causes: no decision latency to hide, a barrier (force, embedded Val, PRM text dependency) in the middle of the round, a saturated engine, an expensive predictor, or remote render round trips. Change one knob at a time.

    Reporting¶

    Include the minimal program, versions of AgentIR and vLLM, model and parser, wire, SpecConfig, the traceback, and whether the failure reproduces with speculation off. For check failures attach the printed report and the timeline. Redact credentials from remote configurations.
