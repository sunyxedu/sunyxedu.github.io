    Runtime configuration¶

    Defaults as shipped in AgentIR 1.3.0. Algorithms and CLI flags may override generation defaults; check the entry point you actually call.

    make_runtime¶

    Argument Default Meaning
    model required HF model id for the main role
    engine_args None extra AsyncEngineArgs (max_model_len, gpu_memory_utilization, ...)
    devices None CUDA_VISIBLE_DEVICES value for the main engine
    judge_model None model for the judge role; otherwise judge aliases main
    judge_engine_args, judge_devices None judge engine overrides; judge_devices alone gives the same model its own engine
    judge_process False run the judge as an OpenAI-compatible vLLM subprocess (text wire only)
    judge_server_attach None attach to an already running judge server instead of launching one
    max_inflight 32 requests per engine; also becomes max_num_seqs
    spec None a SpecConfig, defaults below
    run_seed 20260708 root of every derived seed
    default_params None overrides for the sampling defaults
    wire "text" "text" or "tokens"
    event_granularity "auto" "auto" or "delta"
    chat_template_kwargs None canonical template arguments for main
    judge_chat_template_kwargs None inherits the main value when omitted; {} resets

    EngineSpec additionally exposes scheduling_policy="priority" (required), enable_prefix_caching=True (required), reasoning_parser="auto" (resolved from the model family), expected_version="0.24.0", and vllm_token_drafter=None.

    make_remote_runtime¶

    Argument Default Meaning
    model, base_url required served model name and server base URL
    api_key, headers None authentication
    expected_version "0.24.0" server version pin; None disables only the pin
    certificate_mode "required" the only supported value
    expected_certificate_sha256 None exact deployment pin
    request_timeout 900.0 seconds per HTTP request
    render_cache_entries 128 render memo size
    thinking_token_budget None server-side reasoning budget for the render request
    chat_template_kwargs None sent on every render

    max_inflight, spec, run_seed, default_params as above. The wire is always tokens.

    SpecConfig¶

    Field Default Meaning
    enabled True branch speculation on or off
    window 2 W: maximum unresolved-guard depth eligible for issue
    max_spec_inflight 8 β: concurrent speculative engine requests (also the tool budget, capped by workers)
    depth1_unmetered False depth-1 continuations bypass β
    loop_lookahead None reserved; loop takes its own lookahead argument and defaults to window
    decision_timeout 600.0 seconds before an unresolved decision fails with TimeoutError; None disables
    op_drain_timeout 600.0 seconds run waits for committed effect obligations at retirement
    engine_restart_limit 1 rebuilds per physical engine after EngineDeadError
    judge_prefetch False prefix cache warming (spec-on only)
    prefetch_chunk_tokens 64 new producer tokens between warms
    prefetch_max_inflight 2 prefetch lane per engine
    static_plan None a compiled StaticPlan
    ev_gate False expected-value funding gate
    ev_gate_p_floor 0.05 cold-start probability floor for the gate
    spec_preempt False speculative slot preemption

    Sampling parameters¶

    Defaults: max_tokens=512, temperature=0.8, top_p=0.95 (the tool loop uses temperature=0.0). Accepted keys:

    max_tokens, temperature, top_p, top_k, min_p, logit_bias,
stop, stop_token_ids, repetition_penalty, frequency_penalty,
presence_penalty, logprob_topk, skip_special_tokens,
include_stop_str_in_output, structured

    Any other key is a ValueError at trace time. structured holds exactly one of json, regex, choice, grammar, json_object, structural_tag. Tool loops refuse stop strings. A token-drafting engine refuses min_p and logit_bias. There is no seed parameter.

    Scheduler constants¶

    Constant Value Meaning
    COMMITTED_RETRY_LIMIT 3 engine failures of a committed attempt before the node fails
    SPEC_ATTEMPT_LIMIT 5 failed speculative attempts before the node waits for commitment
    SPECULABLE_ATTEMPT_LIMIT 3 tool-body attempts per phase for speculable tools
    _HOIST_WORLD_CAP 4096 world instances one source-level call may hoist into
    SPEC_PREEMPT_MIN_REMAINING_FRAC 0.25 a victim keeps its slot once this close to done
    PREFETCH_PRIORITY 1,000,000 engine priority of warming requests

    Threads and pools¶

    A Runtime owns one asyncio loop thread (agentir-loop), an op pool (32 workers), a tool pool (32), and a tracer pool (16). A tool that re-enters the runtime (a sub-agent) needs at least two tracer and two tool workers to avoid self-deadlock.

    Source: execution/runtime.py, execution/engine.py, execution/scheduler.py.
