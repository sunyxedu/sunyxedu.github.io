    Python API¶

    This reference covers the supported root exports in agentir.__all__ for 1.3.0. Signatures below emphasize public arguments; types and adapter-specific details live in the linked source modules. Begin with core concepts for the programming model.

    The functions are also available through the agentir.api module. agentir.__version__ reports the package version.

    Prompt construction and generation¶

    lit(s)¶

    Create a Seq from a string or token-ID tuple, according to the runtime wire. The literal belongs to the current tracing context.

    cat(*xs) and fmt(template, **parts)¶

    Compose symbolic prompt states. cat preserves producer and observation segments and canonicalizes adjacent literals. fmt supports named composition without automatically converting every handle into a string.

    Composition supports at most one independent unresolved choice. Combining independent choices into a Cartesian product is not implemented.

    infer(x, *, model="main", logprobs=False, hint=0.0, **params)¶

    Register one continuation. A normal result is a Seq containing its input state and generated output. An unresolved Choice is hoisted into guarded per-member continuations. A Val holding a handle introduces a materialization barrier.

    params are the validated sampling parameters. Request log probabilities with logprobs=True. hint is scheduling advice, not a score used to select the output.

    With tools=registry, this function runs the autonomous tool loop. Its options include max_turns=8, optional max_calls, timeout, and system. The tool loop defaults to eight call slots, a 600-second timeout, 512 output tokens per turn, and temperature zero when not overridden. It returns the final assistant-turn Seq and requires the token wire.

    projection= accepts a prepared streamed projection for advanced custom tool control. It conflicts with autonomous tools= mode. The _stream_projection argument is internal.

    expand(x, k, *, model="main", logprobs=False, hint=0.0, **params)¶

    Register k sampling lanes from a shared input. Each lane receives a distinct draw identity. Returns a list of handles; physical prefix reuse depends on the engine cache.

    Values and publication¶

    text(x) and out_text(x)¶

    Return Val[str] for the complete prompt state or the generated tail, respectively. A selected Choice is resolved under its publication conditions when forced.

    logprobs_of(x) and top_logprobs_of(x)¶

    Return asynchronous per-token log-probability observations. The producer must have been created with the required log-probability observation mode and top-k setting. These functions cannot retroactively request engine observations.

    op(f, *args, pure=False, label="", after=None)¶

    Run a Python function when its inputs are available and its effect conditions permit it. Return a Val. The default fences effects until commitment; pure=True declares replayable computation suitable for speculative execution.

    label identifies the operation in diagnostics. after adds predecessor ordering. Keep expensive blocking work out of event-loop callbacks; op bodies use the operation worker pool.

    collect(vals)¶

    Return one Val containing all results in input order. Callback aggregation waits for every member to settle and reports the first failure in list order. It does not allocate a blocking worker per member.

    force(x, timeout=None)¶

    Materialize a value or handle after the relevant guards allow publication. A rejected world raises Squashed; a surviving failure propagates. This blocks the tracer where a concrete result is required.

    Selection and repetition¶

    choose(pool, by, k=1, hint=None, predict_losers=None, bound=None)¶

    Select k ranked members using a concrete or asynchronous ranking of pool indices. Return a list of rank-specific Choice handles. Rankings must contain distinct, valid integer positions and enough members for k; duplicate pool members are invalid.

    hint carries per-member scheduling information. predict_losers can demote speculative work without removing its surviving execution obligation. bound introduces the distinct bound-commit algorithm.

    gate(x, cond)¶

    Keep x when the condition is true; otherwise squash it. Returns a Choice, with no false-case fallback value.

    loop(init, body, max_iters, lookahead=None)¶

    Call body(state) → (next_state, continue_condition) under successive entry guards. Return the state entering the first round whose condition is false, or the final next state if the bound is exhausted. See loop semantics.

    selection_bounds(pool, bounds, k=1)¶

    Open a bound-commit contest. bounds aligns with the flattened pool; None exempts a member. Attach each member's score with contest.attach(index, score_val), then pass bound=contest to a matching choose. Valid upper bounds and strict rival-score evidence are required.

    prefetch_on_stream(source, build, *, model="judge", chunk_tokens=None)¶

    Register advisory text-prefix cache warming for a transformed future prompt. Enabled only with speculation and SpecConfig.judge_prefetch, and requires the text wire. build(full_text_so_far) returns a prompt string or None; it must be fast and pure. Prefetch outputs are discarded.

    Direct tools and projections¶

    tool(fn, args=None, *, name="", effect="unknown", alpha=None, alpha_name="", after=None)¶

    Register a tool body receiving one JSON argument dictionary. args=None means an empty dictionary. Nested values resolve before canonical argument hashing. effect is "unknown" or "speculable".

    alpha declares a pure observation projection; alpha_name names it. after accepts a tool handle, value, or sequence of such predecessors and waits for their settlement without propagating their values or failures.

    obs(t, alpha=None, *, name="", alpha_name="")¶

    Return a Seq containing a late-bound named observation segment. Its bytes are supplied only when the projection image is materialized.

    observe(t, alpha=None, *, name="", alpha_name="")¶

    Return the structured projected image as a Val. Use this for Python computation on the declared observation.

    ack(t)¶

    Return Val[None] when the body finishes, propagating its failure without reading the observation.

    expect(t, guess, *, alpha=None, name="", alpha_name="")¶

    Return a hit/miss Choice: the guessed string on exact image equality, or a real-observation hole on mismatch. Both surviving paths preserve the declared observation bytes.

    classify(t, cases, *, alpha=None, alpha_name="", name="")¶

    Route exact projected image strings to already-constructed branch values. cases is a closed mapping. An observation outside it is a projection error.

    calls(y)¶

    Expose the prefix-stable ProjectedCalls interface of a generated Seq that was created with a prepared tool-stream projection. It is for custom streamed tool control, not for parsing arbitrary generated text after the fact. See tool_projection in the canonical tools module and streaming design.

    Autonomous tool definitions¶

    ToolDef(fn, effect="unknown", ..., obs=..., guess=..., description=None, input_schema=None)¶

    Configure one named tool in the infer(..., tools={name: definition}) registry. input_schema describes only the arguments, without a provider function wrapper. description defaults to the callable's first docstring line, with the mapping key as the neutral fallback.

    Omitting both the observation contract and guess enables the default exact policy and draft predictor. Explicit obs=Exact() or guess=None suppresses the implicit predictor. The older policy= spelling is accepted, but supplying it together with obs= is an error.

    Observation policy types¶

    Export Contract
    Policy Conservative protocol base: exact image through a real-result hole; shallow call-local sessions
    Exact() Select guesses only on exact equality; otherwise use the real image
    Ignore(text="done") Constant observation without reading the result
    Project(alpha) Pure reduction before exact observation selection
    Enum(cases, by=...) Ordered declared representatives selected through the classifier
    hole() A placeholder filled by the real image
    open() Alias of hole(); distinct from Python's file-opening built-in

    For custom new_session, project, slots, and select, read policy execution.

    Runtime and diagnostics¶

    Export Purpose
    make_runtime(...) Construct local main and optional judge engines
    make_remote_runtime(...) Construct a certified remote token-wire runtime
    EngineSpec Declare the local model, capacity, engine arguments, parser, and drafter
    ModelSpec Bind a role to an engine specification and chat template settings
    Runtime Own engines, tracing contexts, scheduler, worker pools, and ledgers
    SpecConfig Configure branch speculation and advisory policies
    render_timeline(panels, out_path, *, title="") Write a standalone SVG from one or more timeline panels
    Squashed Exception signaling that the requested world was rejected

    See runtime configuration for constructors, defaults, and lifecycle methods. Import TimelinePanel from agentir.diagnostics.viz.

    Canonical advanced modules¶

    agentir.compile provides shape_trace, StaticGraph, GraphBreak, and plan types. agentir.tracing.tools provides tool_projection and the compatibility infer_tools function. Adapter-specific remote and judge-server types live under agentir.execution.

    Although infer_tools, tool_projection, and TimelinePanel remain root attributes for compatibility, they are not in the supported root __all__ surface. New examples use their canonical modules or infer(..., tools=...).
