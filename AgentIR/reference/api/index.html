    Python API¶

    The supported public surface is agentir.__all__ in 1.3.0, re-exported from agentir.tracing.api (the DSL), agentir.execution (runtime), agentir.tracing.tools (tool definitions and policies), and agentir.diagnostics.viz. Everything is importable from the root: from agentir import infer, choose, make_runtime. The same names are also reachable through agentir.api; agentir.__version__ reports the version.

    Prompts and generation¶

    lit(s) → Seq
    A literal from a string, or a token-id tuple on the token wire.
    cat(*xs) → Seq | Choice
    Concatenate Seq, str, Val[str], and at most one unresolved Choice, which the result distributes over. A Val part blocks the tracer until it resolves and commits.
    fmt(template, **parts) → Seq | Choice
    cat with named holes: fmt("Q: {q}\nA: {a}", q=seq1, a=seq2).
    infer(x, *, model="main", logprobs=False, hint=0.0, **params) → Seq | Choice
    One continuation of x. Over an unresolved Choice, one guarded continuation per member (the hoist). Over a Val holding a handle, a barrier. params are the sampling parameters; hint is an advisory funding priority.
    With tools={name: ToolDef} it runs the autonomous tool loop and returns the final assistant turn; extra options max_turns=8, max_calls=8, timeout=600.0, system=None, max_tokens=512, temperature=0.0. Requires the token wire.
    With projection= it uses a prepared tool-stream projection (advanced, see calls).
    expand(x, k, *, model="main", logprobs=False, hint=0.0, **params) → list[Seq]
    k continuations of x: identical prompts, lanes 0..k-1 of one draw, distinct seeds.

    Reading values out¶

    text(x) → Val[str] / out_text(x) → Val[str]
    The full state, or only the generated tail. Accept Seq, Choice, or Val. Resolve as soon as the data exists, even speculatively; publication is enforced by force.
    logprobs_of(x) → Val[list[float]] / top_logprobs_of(x) → Val[list[dict]]
    Sampled-token logprobs (request with logprobs=True) or per-position top-k alternatives (request with logprob_topk=k).
    collect(vals) → Val[list]
    Gather Vals in list order without a worker per element. The first failure in list order is surfaced.
    force(x, timeout=None) → value
    The blocking exit. Waits for x's data and for its guard to be true. Raises Squashed for a rejected world and the deciding computation's own exception for a failed one.

    Control plane¶

    op(f, *args, pure=False, label="", after=None) → Val
    Run f on the worker pool once its inputs resolve. pure=True allows execution on speculative data (a promise of determinism and no side effects). The default waits for its entry guard and its dependencies to commit and runs at most once. after orders the body behind other Vals without consuming their values.
    choose(pool, by, k=1, hint=None, predict_losers=None, bound=None) → list[Choice]
    Pick k members by index. by is a ranking (positions, best first) as a Val or a static int or list. hint is a per-member list of floats or Vals for funding priority. predict_losers is an advisory loser predictor. bound enables bound commit. Duplicate pool members and invalid rankings are errors.
    gate(x, cond) → Choice
    Keep x when cond (a Val[bool] or a bool) is true. No false branch.
    loop(init, body, max_iters, lookahead=None) → state
    body(state) -> (next_state, continue_val). Unrolls predict-taken up to lookahead unresolved rounds (default: the window). Returns the state that entered the round whose condition was false.
    selection_bounds(pool, bounds, k=1) → contest
    Open a bound-commit contest; contest.attach(i, score_val) adds evidence; pass it to choose(..., bound=contest).
    prefetch_on_stream(source, build, *, model="judge", chunk_tokens=None)
    Advisory cache warming for a consumer whose prompt is build(text_so_far). Text wire, speculation and judge_prefetch enabled, else inert.

    Direct tools¶

    tool(fn, args=None, *, name="", effect="unknown", alpha=None, alpha_name="", after=None) → ToolHandle
    Register one tool execution. fn(args_dict). args may nest Val and Choice handles, never Seq. alpha is the declared projection.
    obs(t, alpha=None, *, name="", alpha_name="") → Seq
    The projected image as a late-binding prompt segment.
    observe(t, alpha=None, *, name="", alpha_name="") → Val
    The projected image as a control-plane value.
    ack(t) → Val[None]
    Completion, with the body's failure if any.
    expect(t, guess, *, alpha=None, name="", alpha_name="") → Choice
    A hit-or-miss decision: the guess bytes on exact equality, the real image otherwise.
    classify(t, cases, *, alpha=None, alpha_name="", name="") → Choice
    Route the exact image string through a closed mapping to already-traced branch values; an unlisted image is a ProjectionError.
    calls(y) → ProjectedCalls
    Prefix-stable call slots of a Seq generated with infer(prompt, projection=tool_projection(...)). Slot i's .name and .args are early Val exits; len waits for the terminal inventory. tool_projection lives in agentir.tracing.tools.

    Tool definitions and policies¶

    ToolDef(fn, effect="unknown", *, obs=..., guess=..., description=None, input_schema=None)
    One entry of the tools= registry. input_schema is the argument JSON Schema. With neither obs nor guess, the default is Exact() plus the draft predictor; obs=Exact() or guess=None disables the predictor. policy= is an accepted alias of obs=.
    Export Contract
    Policy base class: new_session, project, slots, select; exact image through one hole
    Exact() real image; guesses verified by byte equality
    Ignore(text="done") constant image, result never read
    Project(alpha) image is alpha(raw)
    Enum(cases, by=fn) closed representatives keyed by by(raw); a hole() case admits the real result
    hole() / open() the slot filled by the real observation (open shadows the builtin; import it deliberately)

    Runtime and diagnostics¶

    Export Purpose
    make_runtime(...) local main engine, optional judge engine, subprocess judge, or attached judge server
    make_remote_runtime(...) certified remote vLLM runtime on the token wire
    Runtime(models, *, role_aliases=None, spec=None, run_seed=..., default_params=None, wire=None, wire_mode="text", event_granularity="auto", op_workers=32, tracer_workers=16) the general constructor over {role: ModelSpec}
    EngineSpec, ModelSpec, SpecConfig engine, role, and speculation configuration
    Squashed raised by force for a rejected world
    render_timeline(panels, out_path, *, title="") SVG timeline from TimelinePanels (import the panel class from agentir.diagnostics.viz)

    Runtime methods: run(fn, *args, problem_key="p0", invocation_key=None, **kwargs), submit(...) (returns a future), warm(timeout=3600.0), chat_prefix(messages, *, role="main", tools=None, ...), ledger_for(problem_key), events_for(problem_key), snapshot(), close(), and the context-manager protocol.

    Not in __all__, still useful¶

    agentir.api.settle(choice) waits for a placeholder and returns the bound member handle. agentir.api.pace_unrolling(selections, lookahead) throttles hand-written round loops. agentir.api.speculation_window() reports the effective window. agentir.compile.shape_trace and StaticGraph are the static compiler. agentir.diagnostics.reference.reference_differential and run_serial are the verification entry points. infer_tools, tool_projection, and TimelinePanel remain importable from the root for compatibility.

    Source: __init__.py, tracing/api.py, tracing/tools.py, tracing/policy.py.
