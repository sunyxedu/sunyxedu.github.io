    Static shape compilation¶

    shape_trace executes a program over symbolic values to discover its structure without loading a model or running Python op bodies. It produces a cyclic, parametric graph that can explain the program and optionally guide speculative funding.

    It is a supported module in this checkout: agentir.compile. There is no agentir compile CLI subcommand.

    Compile a small program¶

    This example runs with only the base AgentIR installation:

    from agentir import cat, choose, collect, expand, force, infer, lit, op, out_text
from agentir.compile import shape_trace


def rank_by_length(answers):
    return sorted(range(len(answers)), key=lambda i: len(answers[i]))


def program(question):
    candidates = expand(lit(question), 3, max_tokens=64)
    answers = collect([out_text(candidate) for candidate in candidates])
    ranking = op(rank_by_length, answers, pure=True)
    best = choose(candidates, by=ranking, k=1)[0]
    final = infer(cat(best, lit("\nSummarize:")), max_tokens=32)
    return force(out_text(final))


graph = shape_trace(program, "Explain prefix caching.")
print(graph.summary())
with open("program-shape.json", "w", encoding="utf-8") as output:
    output.write(graph.to_json())

    The result describes generation shells, a ranking operation, a selection, and guarded continuations. No answer was generated, and rank_by_length was not evaluated on model outputs.

    Read the graph¶

    Graph element Meaning
    Node shell The static part of an engine request, operation, decision, or bounded tool slot
    cat_data edge Prompt-spine data flows from one shell to another
    transform_data edge A Python operation transforms data between shells
    control edge A selection determines which continuation survives
    Loop body and back-edge Repeated structure with carried state and a trip count or bound
    Guard information Selection size, retained ranks, and possible continuations

    The graph stores what is known before dynamic values exist. Tool-slot names and arguments, and chat-rendered tool turns, may still need runtime binding. An identity note marks cases without a fully precomputed identity prefix.

    Use StaticGraph.from_json(graph.to_json()) to restore the serialized graph. Static graphs describe possible structure; runtime ledgers describe actual executions.

    Loops are represented as loops¶

    The compiler recognizes repeated isomorphic blocks and folds them into a body with back-edges. It accounts for loop-carried dependencies and identity occurrence strides. A repeated candidate map should not accidentally become a temporal loop.

    The explicit loop primitive can expose its body once with a bounded trip annotation. The compiler does not need to expand every possible runtime iteration into separate nodes.

    Produce an optional scheduling plan¶

    from agentir import SpecConfig

spec = SpecConfig(static_plan=graph.plan())

    Pass this spec to a runtime that executes the same program shape and configuration. The plan matches decision sites and provides per-decision speculation-depth and sibling-exclusivity budgets.

    This is a funding plan: it does not alter guard truth, node identity, committed work, or the program's return value. A plan is also not a prediction of how long an engine request will take.

    Recognize graph breaks¶

    The compiler raises GraphBreak with a source location when Python tries to inspect a symbolic value through unsupported truth conversion, length, iteration, or string materialization. It does not silently switch to a different compilation strategy.

    Live chat-template rendering, dynamic Python control flow, and currently unmodeled operations such as expect or classify can also prevent shape compilation. A runtime-valid program is not necessarily statically traceable. Materialization in SAL-style search is one example of a meaningful boundary.

    Keep supported computation in DSL operations if the shape is useful to compile. Otherwise run the program normally without a static plan; dynamic tracing remains the execution path.

    Source: tracer.py, graph.py, fold.py, and shape tests.
