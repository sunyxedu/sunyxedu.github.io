    Compile, algorithms, diagnostics, bench¶

    compile/: tracer.py (shape context), symbols.py (symbols and GraphBreak), fold.py (loop detection), graph.py (shells, edges, identity finalize, plans). Tests test_compile_shape, test_compile_plan.

    algos/: eight algorithms plus common.py. Tests test_algo_traces, test_common, test_beam_judge_scorer, test_fasttts_parts.

    diagnostics/: reference.py (serial interpreter, differentials), tool_audit.py, viz.py. Tests test_reference, test_scheduler_differential, test_slow_tool_audit, test_viz.

    bench/: tasks.py, runner.py, stats.py, prm.py, telemetry and evidence modules. Tests test_bench_stats, test_gpu_telemetry, test_vllm_metrics_telemetry, and the test_ordinary_*, test_terminal_*, test_analyze_*, test_bench_tools_* suites for the experiment scripts.

    cli.py wires list, warm, bench, refdiff, check; test_cli_check_gate pins the exit-status contract.

    integrations/harbor/: protocol.py (dependency-free boundary), agent.py (Harbor BaseAgent, ATIF), runner.py (runtime pool, shell bridge, shell tool). Tests test_harbor_protocol, test_harbor_adapter, test_harbor_runner.

    Changing things at the right layer¶

    • A change to what a prompt is (spine, parameters, draw scoping) touches core and must keep test_ir, test_trace, test_reference, and test_compile_shape (identity parity) green.
    • A change to when work runs touches scheduler.py or tool_scheduler.py and must keep the scheduler differential green: bytes may not move.
    • A change to parsing touches tool_stream.py and the certificate; check streamed prefixes, terminal agreement, retries, and the remote protocol tests.
    • A change to a public contract updates the corresponding reference page; scripts/check_docs.py checks that every export and every SpecConfig field is documented.

    Run python -m pytest (engine-free) before a real-engine agentir check.
