    Source map¶

    Use this map to move from a behavior to its implementation and tests. The runtime is easiest to understand in dependency order: core representation, tracing, execution, then tools and integrations.

    All package paths below are relative to src/agentir. Tests use deterministic engines and protocol fixtures where useful, with separate real-engine checks for integration behavior.

    Compilation and algorithms¶

    compile/tracer.py runs symbolic shape tracing. symbols.py defines symbolic values and graph breaks; fold.py identifies repeated regions; graph.py builds and serializes cyclic node shells and scheduling plans. test_compile_shape and test_compile_plan check structure, folding, identity parity, and funding behavior.

    The eight files in algos implement self-consistency, best-of-N, beam search, SAL beam, reflexion, MCTS, heavy, and cascade. common.py provides prompts, parsers, normalization, and ranking. test_algo_traces, test_common, test_beam_judge_scorer, and test_fasttts_parts cover these layers. Read the algorithm guide before treating their graphs as interchangeable.

    Diagnostics and measurement¶

    diagnostics/reference.py contains the independent serial interpreter, recording/replay, and scheduler differential. tool_audit.py performs opt-in replayability audits; viz.py renders SVG timelines. Corresponding suites include test_reference, test_scheduler_differential, test_slow_tool_audit, and test_viz.

    In bench, tasks.py loads datasets, runner.py manages benchmark arms and records, stats.py provides paired statistics, and prm.py builds reward-model scoring requests. gpu_telemetry.py and vllm_metrics_telemetry.py collect resource samples; terminal_drafter_evidence.py validates shared evidence contracts.

    cli.py wires these pieces into list, warm, bench, refdiff, and check. test_cli_check_gate verifies that both semantic gates affect command success.

    Integrations, examples, and experiment scripts¶

    integrations/harbor/protocol.py defines the runner/environment boundary, agent.py implements Harbor's adapter and ATIF persistence, and runner.py builds and caches the actual AgentIR runtime and shell tool. The three test_harbor_* suites cover the boundary, adapter, and runner.

    examples/quickstart.py is the small complete program. examples/subagent_as_tool.py covers nested invocations, leaf tools, and predicted summaries.

    The larger scripts directory groups experimental drivers, analyzers, frozen locks, model probes, Slurm launchers, and cluster wrappers. Use the experiment archive to choose a family. The test_ordinary_*, test_terminal_*, test_analyze_*, and test_bench_tools_* suites validate their manifests, analysis eligibility, and orchestration boundaries.

    Make a change at the right layer¶

    If a prompt identity changes, start with core identity and serial parity tests. If ordering changes, inspect both the engine and tool scheduler and effect-drain behavior. If a parser changes, check streamed prefixes, terminal agreement, retries, and the certificate contract. If an analysis changes, preserve its declared unit of comparison and validate raw-artifact provenance.

    Run the focused tests for the changed boundary before a real-engine experiment. Update the corresponding explanation and reference entry when a public contract changes.
